# Evidence model

- **PROVEN** — directly established through control flow, API schema, config, or a concrete call site.
- **STRONG EVIDENCE** — multiple consistent artifacts support it, but one runtime or semantic link is missing.
- **PLAUSIBLE** — architecture is compatible with the evidence but not established.
- **UNKNOWN** — evidence is insufficient.
- **DISPROVEN** — directly contradicted by recovered implementation.

Agents must use these terms consistently. Comparative MHI2Q/MHI3 findings are
not MPR3 facts without independent evidence.
